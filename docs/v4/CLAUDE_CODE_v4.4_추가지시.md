## 1. 색인 범위 축소와 색인 순서

- 색인 프로필은 **`hdr-qwen3`와 `nohdr-qwen3` 두 개만** 만든다. `hdr-bgem3`(bge-m3) 프로필은 만들지 않는다(설정에서 제거). 이미 일부 만들어졌으면 쓰지 않는다.
- 색인 순서: **`hdr-qwen3`를 먼저 완성**하고 R1, R2, R3, R5(2절 번호)를 실행한 뒤, `nohdr-qwen3`를 만들어 R4를 실행한다. 헤더 있는 색인만으로 주 결과 대부분을 낼 수 있으므로 결과를 먼저 볼 수 있다.
- a480d80의 임베딩 체크포인트(`data/embed_cache/`)를 그대로 써서 중단 지점부터 이어 간다. 중단 전 체크포인트가 있으면 재사용하고, 없으면 새로 한다.
- **속도 점검을 먼저 보고한다.** 파싱, OCR, 임베딩, BM25 토큰화에 걸린 시간 비율과 단위/초 처리량을 E1에 적는다. 출력에 영향이 없는 조정(임베딩 배치 크기 `EMBED_NUM_BATCH`, 파싱 워커 수, 체크포인트 주기)은 자유롭게 바꾸되, **텍스트나 벡터를 바꾸는 조정(OCR 엔진·DPI, 양자화, 모델 태그, 광고 메일 규칙 등)은 바꾸지 말고 제안만 한다.** OCR이 병목이면 스캔 PDF 비율과 OCR 페이지 수를 함께 보고한다.

## 2. 실행 축소: 9개 → 5개, 사전 비교 11개 → 4개

논문은 실행 5개만 보고한다. 하네스 번호와 논문 번호 대응은 다음과 같다. **보고서와 표의 실행 이름은 논문 번호(R1~R5)로 출력**한다.

| 논문 | 하네스(기존) | 색인 | 구성 |
|---|---|---|---|
| R1 | R2 | hdr-qwen3 | BM25 단독 |
| R2 | R4 | hdr-qwen3 | 밀집 검색 단독 |
| R3 | R6 | hdr-qwen3 | 하이브리드(RRF k=60) |
| R4 | R7 | nohdr-qwen3 | 하이브리드 + 재순위, 헤더 없음 |
| R5(기본) | R8 | hdr-qwen3 | 하이브리드 + 재순위, 헤더 있음 |

- **실행하지 않는 것:** 기존 R1, R3, R5(헤더 없는 단일 검색과 하이브리드), R9(bge-m3).
- **사전 비교 4개(Holm 단일 계열, S17 nDCG@10):** R1→R3, R2→R3, R3→R5, R4→R5 (하네스 번호로는 R2→R6, R4→R6, R6→R8, R7→R8). `config.yaml` 비교 목록을 이 4개로 바꾼다. 검정 방법(Fisher 무작위화 10,000회 양측, bootstrap 1,000회)은 그대로다.
- **판정 풀:** 실행 5개의 상위 10개 합집합. 9개 기준으로 만든 시트가 있으면 폐기하고 5개 기준으로 다시 만든다.
- **표:** T2(주 결과)는 5개 실행 행. **T3, T4, T5, T6은 만들지 않는다.** T8(집합별)은 R1, R2, R3, R5 4열, nDCG@10과 P@10. F1(실패 분석)은 R5 기준이며 단위별 순위 기록은 실행 5개.
- **언어별 보조 값(표 아님, 본문용):** 등급 2 단위가 현지 언어인 S17 질문 수, 그 질문에서 R5가 등급 2 단위를 상위 10개에 넣은 질문 수, 같은 질문에서 R1과 R2 각각의 상위 10개 포함 여부.
- 논문 표 번호: [표 12] = T2, [표 13] = T8, [표 14] = G1(4절), [표 15] = F1. 이전 문서의 [표 18]~[표 21] 표기는 이렇게 읽는다.

## 4. 응답 생성 평가 하네스 G1 (논문 RQ3, 4.6절, [표 14])

**목적.** 로컬 LLM(Gemma 4 12B)이 검색된 후보 가운데 결정적 증거를 골라 근거를 인용하며 답하는지 감사인이 판정한다.

**4.1 답변 생성**
- 응답 시간 측정(5절)에서 생성한 답변을 그대로 쓴다. 따로 다시 생성하지 않는다. 대상은 질문 45개 전체이며 표와 판정 시트는 S17만 만든다.
- 컨텍스트는 **서비스 경로와 같게** 단위 대표 조각(헤더 + 조각 본문, `part.full_text`)으로 맞춘다. 현재 `latency.py`의 `GEN_UNIT_MAX_CHARS` 4,000자 절단 방식을 서비스 `_format_source_context`와 같은 함수로 바꾼다.
- 질의마다 기록: qid, 답변 전문, 컨텍스트 단위 ID 5개(순위 순), 답변에서 추출한 인용 번호 목록(`[출처 n]` 정규식, 서비스 인용 검증 함수 재사용), 인용 번호 → 단위 ID 매핑, 모델 태그. 저장 위치 `runs/gen/answers.jsonl`(P0 경로).

**4.2 답변 판정 시트(`judge gen` 명령 신설)**
- 질문별 한 장: 질문 문장, 답변 전문(인용 번호 유지), 컨텍스트 단위 5개(헤더 + 본문, 6,000자 절단 규칙 동일, 현지 언어 단위는 한국어 번역 첨부). 단위 등급은 보여 주지 않는다.
- 판정 항목: 인용별 "뒷받침함 / 뒷받침하지 않음"(답변 문장 번호와 인용 번호 기준); 답변별 근거 없는 주장 수(정수), 무근거 응답 여부("찾을 수 없다"류 자동 판정 + 판정자 확인), 유용성(2 바로 활용 / 1 참고 / 0 무용).
- 판정자 A, B 모두 S17 전체(17개)를 독립 판정한다. 순서는 seed 고정 셔플. 인용이 없는 답변은 인용 정확도 분모에서 빼고 건수를 따로 적는다.

**4.3 표 G1([표 14])** — S17 기준

| 지표 | 정의 |
|---|---|
| 인용 정확도 | 뒷받침하는 인용 수 / 전체 인용 수 (질문별 평균과 전체 합산) |
| 결정적 증거 인용률 | 컨텍스트 5개 중 등급 2 단위 가운데 답변이 인용한 비율. 등급 2가 있는 질문만, n 표기. qrels 사용 |
| 근거 없는 주장 | 1개 이상인 답변 수 / 17, 전체 주장 수 합 |
| 무근거 응답 | 컨텍스트에 등급 ≥1 단위가 없는 질문 중 "찾을 수 없다"고 답한 비율, n 표기 |
| 유용성 | 평균과 0/1/2 분포 |
| 판정자 일치도 | 인용별 Cohen's kappa(이진), 유용성 QWK(n_levels=3), 근거 없는 주장 수 완전 일치율 |

불일치는 4.1.3과 같이 협의로 최종값을 정하고 표에는 최종값과 일치도를 함께 낸다. 보고서에는 집계값만 넣는다.

## 5. 응답 시간과 GPU 메모리: 표 대신 값만

- 측정은 **R5(하네스 R8) 한 실행**으로 한다. R6, R9 측정은 하지 않는다. 세 모델 적재 상태, 질문 45개, 사전 3개 실행 후 질의마다 순서 무작위 5회 반복(기존 방식).
- 보고 값: 검색 전체 p50/p95, 그중 재순위 p50, 응답 생성 포함 질의당 전체 시간 p50, 세 모델 적재 시 GPU 최대 사용량(nvidia-smi, torch, ollama ps), 재순위 입력 4,096토큰 초과 절단 비율. 논문 4.3절 본문 두 문단에 들어간다. 단계별 표(T7)는 만들지 않아도 된다.
- 응답 생성은 질의당 1회이며 이 답변이 4절 G1의 입력이다.

## 6. 보안 모드 해제 시 외부 API 격리

논문 3.5절 문장: "외부 API 연결(보안 모드 해제)은 감사인이 인터넷 공개 정보를 조사할 때 쓰며, 이 경로는 케이스 색인, 벡터, 검색 결과를 외부 API에 보내지 못하도록 코드 수준에서 막았다."

현재 코드(`src/llm/router.py` 5행 주석, `engine.py` 304행 부근)는 보안 모드 OFF에서 검색된 컨텍스트를 외부 LLM에 그대로 보낸다. 위 문장이 참이 되도록 바꾼다.
- `secure_mode=False`이면 `generate`/`generate_stream`에 `context=[]`를 넘기고(케이스 검색 결과 제외), 시스템 프롬프트를 "케이스 자료 없이 일반 질의에 답한다"는 외부용으로 바꾼다. 출처 표시도 붙이지 않는다.
- 외부 LLM 클라이언트에 들어가는 메시지에 케이스 텍스트가 섞이지 않는지 단위 테스트를 추가한다.
- UI에는 보안 모드 해제 상태가 "케이스 자료를 쓰지 않는 외부 조회"임을 표시한다.
- 바꾸기 어렵거나 운영 요구가 다르면 그대로 두고 보고한다. 그러면 논문 문장을 코드에 맞춘다.

## 7. 환경 기록(E1)에 넣을 값

- CPU AMD Ryzen 7 3700X(8코어 16스레드), RAM 64GB, NVMe SSD 2TB, GPU RTX 3090 24GB. OS와 버전은 E1에서 자동 수집한 값을 쓴다.

## 8. 코퍼스 보고 항목(T1, [표 6], [표 7])

- T1 주석에 `ads_removed`(광고 메일 제외 건수)를 넣는다. 논문 4.1.1절에 자리가 있다.

## 9. 판정자 수

판정자 B 층화 표본(search 4, meta 1, nonsearch 6 = 11개)은 유지한다. 판정자 C가 추가되면 B와 **겹치지 않는** 11개(같은 층화, 다른 seed)를 뽑는 옵션 `c_queries`를 만든다. 일치도는 A–B, A–C를 각각 내고 질의 수를 함께 적는다. 답변 판정(G1)은 C도 17개 전체를 한다.
